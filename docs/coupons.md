# ระบบคูปองส่วนลด

## การใช้งาน

- Admin: อีเว้นท์ → คูปองส่วนลด (`/admin/coupons`)
- สร้างฉบับร่าง กำหนดเงื่อนไข แล้วเปิดแจก; วิธีแจกมีสมาชิกใหม่ สุ่มแจก เลือกผู้รับ และสมาชิกกดรับเอง
- สุ่ม/เลือกแจกทำจากรายละเอียดคูปอง ครั้งละไม่เกิน 500 คน รายละเอียดมีรายการผู้ถือครองและประวัติการใช้พร้อมแบ่งหน้า
- ลูกค้า: ตะกร้า → ใส่คูปองส่วนลด → คูปองของฉัน / รับคูปองเพิ่ม
- Badge นับคูปองที่ถือครองและใช้กับตะกร้าปัจจุบันได้ ส่วนคูปองเปิดรับแสดงข้อความแยกกัน

## กติกา

- หนึ่งคูปองต่อคำสั่งซื้อ ใช้ร่วมกับโปรโมชั่นสินค้าได้
- ยอดซื้อขั้นต่ำและฐานส่วนลดเปอร์เซ็นต์ = ยอดสินค้าหลังโปรโมชั่น ไม่รวมค่าจัดส่ง
- จำนวนชิ้นรวมทุกสินค้า; จำนวนรายการนับสินค้าแตกต่างกัน; เงื่อนไขที่กำหนดต้องผ่านทุกข้อ
- ส่วนลดไม่เกินยอดสินค้า คูปองเปอร์เซ็นต์กำหนดเพดานส่วนลดได้ ไม่มีวันหมดอายุใช้ NULL
- หนึ่งคนรับหนึ่งสิทธิ์ต่อคูปองตลอดอายุแคมเปญ แม้ใช้หมดหรือคืนสิทธิ์แล้ว การรับใช้โควตาผู้รับทันที
- กดเลือกเป็นการดูยอดเท่านั้น ตัดจำนวนครั้งใน transaction เดียวกับสร้างคำสั่งซื้อสำเร็จ
- สมาชิกใหม่ต้องสมัครผ่าน OTP หลังเปิดแจก ไม่รวมสมาชิกเดิมหรือบัญชีที่ admin สร้าง
- หยุดแจกไม่กระทบสิทธิ์ที่ถืออยู่ ลบได้เฉพาะฉบับร่างที่ยังไม่แจก
- เมื่อแจกแล้วล็อกส่วนลด เงื่อนไข วิธีแจก จำนวนครั้ง และวันหมดอายุ; ยังแก้ชื่อ คำอธิบาย สถานะ และจำนวนผู้รับ (ไม่ต่ำกว่าที่แจกแล้ว) ได้
- ยกเลิกก่อนชำระเงินคืนสิทธิ์อัตโนมัติครั้งเดียว คงวันหมดอายุและประวัติเดิม ไม่เพิ่มโควตาการแจก
- ยกเลิกออเดอร์ที่ชำระแล้ว: admin ยืนยันว่าได้คืนเงินจริงนอกระบบ พร้อมเหตุผล ก่อนคืนสิทธิ์ ระบบบันทึกประวัติและสถานะ refunded แต่ไม่โอนเงิน
- คำสั่งซื้อที่ยกเลิกเปิดกลับไม่ได้ คำสั่งซื้อที่ชำระแล้วแก้ยอดสินค้าไม่ได้
- แก้รายการออเดอร์ที่ยังไม่ชำระใช้เงื่อนไข snapshot เดิม หากไม่ผ่านต้องยืนยันถอดคูปองและคืนสิทธิ์พร้อมการแก้ใน transaction เดียว
- เมื่อคูปองครอบคลุมยอดทั้งหมดและไม่มีค่าจัดส่ง ระบบบันทึกชำระด้วยคูปอง ไม่ต้องส่งสลิป

## ฐานข้อมูล

Migration: `database/tb_event_coupons.sql`

| ตาราง                           | ข้อมูล                                                    |
| ------------------------------- | --------------------------------------------------------- |
| tb_event_coupons                | เงื่อนไขแคมเปญ สถานะแจก โควตาและจำนวนผู้รับ               |
| tb_user_coupons                 | สิทธิ์ที่แต่ละสมาชิกถือครอง ช่องทางรับและจำนวนครั้งที่ใช้ |
| tb_shopping_order_coupon_usages | คำสั่งซื้อ ส่วนลด snapshot และประวัติคืนสิทธิ์            |

ทั้งสามตารางมี id, uuid, created_by/at, updated_by/at, deleted_by/at ครบ พร้อม FK/unique/check constraints
เพิ่ม unique index ของ tb_users.uuid เพื่อรองรับ FK และเพิ่ม order_user_coupon, order_coupon_discount, order_coupon_snapshot ใน tb_shopping_orders
order_discount ยังคงเป็นส่วนลดโปรโมชั่นรายสินค้า เพื่อไม่เปลี่ยนความหมายข้อมูลคำสั่งซื้อเก่า

```powershell
node --env-file=.env scripts/coupons-db.mjs migrate
node --env-file=.env scripts/coupons-db.mjs seed
node --env-file=.env scripts/coupons-db.mjs status
```

Seed รันซ้ำได้โดยไม่สร้างซ้ำ/รีเซ็ตโควตา: คูปองต้อนรับสมาชิกใหม่ 20 คนแรก ลด 50 บาท เมื่อซื้อครบ 500 บาท ใช้คนละ 1 ครั้ง ไม่มีวันหมดอายุ เริ่มนับจากการสร้างและเปิดแจกครั้งแรก ไม่มีการแจกย้อนหลัง
ควรเปิดใช้งานโค้ดที่รองรับคูปองก่อนเปิดแจก และใช้ migration ก่อนรันโค้ดรุ่นนี้

## API

| Endpoint                            | สิทธิ์/หน้าที่                                                                                               |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| GET/POST /api/coupon                | Admin รายการแบบแบ่งหน้า / สร้าง                                                                              |
| GET/PUT/DELETE /api/coupon/:uuid    | Admin รายละเอียด / แก้ไข / soft-delete                                                                       |
| POST /api/coupon/:uuid/distribute   | Admin สุ่มหรือเลือกผู้รับ                                                                                    |
| POST /api/coupon/:uuid/claim        | สมาชิกกดรับแบบไม่ซ้ำ                                                                                         |
| GET /api/user/coupons               | คูปองของสมาชิก คูปองเปิดรับ จำนวน badge และเงื่อนไขตะกร้า                                                    |
| POST /api/coupon/quote              | ตรวจสิทธิ์และราคาใหม่ ไม่ตัดสิทธิ์                                                                           |
| POST /api/order                     | ส่ง order_user_coupon_uuid พร้อม expected discount/merchandise total; server คำนวณจริงและปฏิเสธยอดที่เปลี่ยน |
| POST /api/order/:uuid/coupon/remove | Admin ถอดคูปองจากออเดอร์ที่แก้ไขได้                                                                          |
| POST /api/order/:uuid/coupon/return | Admin คืนสิทธิ์ออเดอร์ยกเลิก พร้อมยืนยันคืนเงินจริงหากเคยชำระ                                                |
